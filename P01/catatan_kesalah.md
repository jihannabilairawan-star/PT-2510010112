# Catatan Kesalahan Program
| Berkas | Jenis kesalahan | Pesan yang muncul (salin baris pertamanya) | Cara kamu mengetahuinya |
|---|---|---|---|
| k1_sintaks.cpp | Syntax error, terjadi karena ada bagian penulisan kode yang tidak lengkap sehingga compiler tidak dapat membaca program dengan benar. | [isi sesuai pesan error saat dijalankan] | Program tidak berhasil dibuat menjadi file .exe setelah proses compile. |
| k2_nama.cpp | Name error, terdapat penggunaan nama variabel yang tidak sesuai dengan nama yang sudah didefinisikan. | [isi sesuai pesan error saat dijalankan] | Compiler memberikan pemberitahuan bahwa nama yang digunakan tidak dikenali. |
| k3_runtime.cpp | Runtime error, program berhasil dibuat tetapi mengalami masalah ketika sedang dijalankan dengan kondisi input tertentu. | [isi sesuai hasil saat dijalankan] | Kesalahan baru terlihat ketika program dijalankan dan diberikan input 0. |
| k4_logika.cpp | Logic error, program dapat dijalankan tetapi perhitungan yang dilakukan menghasilkan nilai yang keliru. | [isi sesuai hasil saat dijalankan] | Hasil rata-rata yang ditampilkan tidak sesuai dengan perhitungan yang seharusnya. |

# Kesimpulan
Menurut saya, kesalahan logika merupakan jenis kesalahan yang paling berbahaya karena program tetap dapat berjalan tanpa menampilkan pesan error, tetapi hasil yang diberikan bisa salah. Kesalahan tersebut dapat sulit diketahui jika hasil program tidak diperiksa dengan teliti.
